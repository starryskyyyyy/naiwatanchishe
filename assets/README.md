# 游戏贴图

已根据用户提供的黄色角色参考图生成透明PNG：蛇头保留大绿眼睛与小嘴，蛇身和转弯块为无花纹黄色，蛇尾从黄色渐变到黑色。苹果、梨、桃子参考圆润小脸角色生成，每次等概率随机出现一种。

之后可提供透明背景PNG或WebP，每张正方形画布，主体在中间、尽量填满，不留大面积空白。建议源图至少128×128。放入此目录，在skin.js填写路径：

| 文件 | 默认朝向 |
| --- | --- |
| head.png | 蛇头朝右 |
| body.png | 蛇身水平连接左右 |
| corner.png | 转弯蛇身连接左侧与下侧 |
| tail.png | 尾尖朝右，连接身体的一端在左 |
| apple.png | 苹果正向，无需旋转 |
| pear.png | 梨正向，无需旋转 |
| peach.png | 桃子正向，无需旋转 |

也支持上述同名.webp文件。游戏会按方向旋转蛇头、身体与蛇尾。corner可选，不提供时转弯处使用body占位或贴图。skin.js中的null保持几何占位；文件加载失败也会回退，不影响游戏规则。将来若需动态舌头或动画帧，可在渲染层单独扩展。

当前蛇头后部为圆柱；所有连接口在游戏中统一为格子宽度的50%，位于各边中心。`SnakeSkinLayout`记录原图连接口位置，渲染器用分段缩放对齐。以后更换素材时，需要同步调整这些位置；如果新素材本身已经精确对齐，可以删除对应的布局配置。
